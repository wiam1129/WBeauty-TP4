
# WBeauty - TP4

## Description
WBeauty est une application web de gestion des commandes
de produits de beauté.

Elle utilise HTML, CSS, Bootstrap, JavaScript et JSON.

## Structure du projet

- html/ : page HTML de l'application
- css/ : fichier de style CSS
- data/ : fichiers JSON des clients, produits et commandes
- js/ : fichiers JavaScript de l'application

## Fonctionnalités

- Chargement de trois fichiers JSON
- Affichage des commandes
- Calcul des montants des commandes
- Recherche par nom du client
- Filtrage par statut et catégorie
- Affichage des détails d'une commande
- Gestion des erreurs de chargement

## Lancement du projet

1. Ouvrir le dossier tp4 dans VS Code.
2. Ouvrir html/index.html.
3. Lancer la page avec Live Server.
4. Utiliser la recherche et les filtres pour consulter les commandes.
